# BTCAi Wallet
Experimental Android RPC client for an existing local BTCAi node. Not a standalone wallet. Build with GitHub Actions or Gradle 8.9 and Android SDK 35. Uses localhost:19337/wallet/BTCAi only. Enter existing RPC username/password in app; credentials are held in memory. Keep RPC bound to localhost, never expose it through a tunnel. If node uses cookie authentication only, configure a dedicated rpcauth credential locally. Back up the existing node wallet separately. Debug APK is not a production release. No QR or app PIN yet. Test on a disposable wallet before real transfers.
